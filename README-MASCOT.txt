EFIM RISE — сайт с разделом «Маскот для бренда»

Просмотр: распакуйте ZIP и откройте index.html.
Публикация: сохраните резервную копию действующего сайта, затем загрузите содержимое этой папки в его корневой каталог. Архив не публикует сайт автоматически.

Добавлено: раздел #mascot, пункт меню, цены из рекламного поста, пояснение озвучки, кнопки Telegram. Оригинальные проекты и контакты сохранены.

ВАЖНО ОБ ИЗОБРАЖЕНИИ
assets/mascot.svg — новая векторная иллюстрация по мотивам прикреплённого поста, НЕ оригинальный 3D-персонаж и не точная копия изображения. Бинарный файл вложения не был доступен для включения в архив.
Чтобы поставить свой оригинал: сохраните его в assets/mascot.png; в index.html замените src="assets/mascot.svg" на src="assets/mascot.png". Если пропорции не квадратные, обновите width и height в том же теге img; CSS сохранит естественные пропорции.

Проверки: существование локальных ресурсов, якоря, уникальные ID, цены, корректный XML SVG, целостность ZIP. Визуальный тест в браузере не выполнялся.
Исходные внешние ссылки Яндекс Диска сохранены; ссылки /client/disk/ могут требовать входа в аккаунт владельца. Для публичного портфолио замените их на ссылки общего доступа.
