# EFIM RISE — загрузка и редактирование

## Загрузка на хостинг / GitHub Pages
Распакуйте ZIP. Загрузите index.html, style.css, script.js и папку assets в корень сайта, заменив старые файлы. Не загружайте сам ZIP вместо файлов сайта. На GitHub используйте Add file → Upload files → Commit changes. Дождитесь завершения публикации Pages и обновите страницу Ctrl+F5.

## Замена превью без редактирования кода
Замените соответствующий JPG в assets, сохранив имя:
- preview-tochka.jpg — Точка связи
- preview-unicorn.jpg — Единорог+
- preview-sto-filter.jpg — STO Filter
- preview-omoda.jpg — Omoda
Это должны быть настоящие JPG, а не PNG с переименованным расширением.
Если используете PNG/WebP с другим именем, исправьте src у нужного img в index.html.
Все обложки имеют рамку 16:10. Изображение заполняет рамку и обрезается по краям без растягивания. Логотип assets/logo.svg используется только в шапке.

## Добавление работы
Скопируйте один блок <article class="project" ...>...</article> внутри .project-grid в index.html. Вставьте его перед закрывающим тегом сетки. Замените src изображения, alt, заголовок h3, описание p и href ссылки. Добавьте изображение в assets. Теги фильтра: 3d, ad, exp. При необходимости обновите цифры в кнопках фильтра.
